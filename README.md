# 가게 홍보물 자동 만들기

매장 사진과 가게 정보를 넣고 한 번 실행하면, 인스타그램용 사진과 채널별 홍보 문구를 만들어 주는 프로그램입니다.

## 하는 일

- **사진 변환**: `자료` 폴더의 jpg, png 사진을 가운데 기준으로 잘라 1080 x 1080 정사각형으로 만듭니다. 사진이 찌그러지지 않고, 원본은 건드리지 않습니다.
- **로고 넣기**: 오른쪽 아래에 `자료/로고.png`를 작고 약간 투명하게 넣습니다. 로고 파일이 없으면 이 단계는 건너뜁니다.
- **문구 만들기**: `자료/가게 정보.txt`를 읽어 아래 문구를 만듭니다. 사장님 말투에 맞춰 "~합니다"체로, 이모지 없이 씁니다.
  - 인스타그램: 감성형 / 정보형 / 이벤트형 + 해시태그 10개
  - 네이버 블로그: 500자 안팎, 해시태그 없음
  - 카카오톡 단골 공지: 3줄 이내
- **결과 정리**: `완성/오늘날짜/` 폴더에 모읍니다. 같은 날 다시 실행하면 같은 폴더에 사진 번호와 문구가 이어서 쌓이고, 기존 파일은 지우지 않습니다.

## 실행 방법

필요한 것: Python 3, Pillow(`python3 -m pip install Pillow`)

```
python3 사진변환.py
```

맥에서는 바탕화면 아이콘을 더블클릭하는 방식도 쓸 수 있습니다. (이 저장소에는 아이콘이 포함되어 있지 않습니다.)

## 폴더 구조

```
.
├─ 사진변환.py      사진 변환 + 로고 + 문구 만들기를 한 번에 실행
├─ 문구생성.py      채널별 문구 만드는 부분
├─ 사용설명서.txt   매주 쓰는 방법 (비개발자용)
├─ 자료/            사진, 로고.png, 가게 정보.txt, 내 말투.txt
└─ 완성/            결과물 (날짜별 폴더)
```

## 매주 쓰는 법

1. `자료`의 지난주 사진을 치우고 이번 주 사진을 넣습니다.
2. `자료/가게 정보.txt`의 "이번 주 홍보할 것"을 고칩니다.
3. 위 명령어를 실행합니다.

자세한 설명은 [사용설명서.txt](사용설명서.txt)를 봐 주세요.

## 참고

- 문구는 AI가 쓰는 것이 아니라, `가게 정보.txt` 내용을 문장 틀에 끼워 넣어 만듭니다. 그래서 정보에 없는 내용은 만들어 내지 않습니다.
- `가게 정보.txt`의 신메뉴 줄은 `- '메뉴이름' 가격원, 설명, 설명` 모양, 할인 줄은 `할인`이 들어간 모양이어야 읽습니다.
