브릿지 커피 홍보물 만들기 - 사용설명서
==========================================

이 프로그램이 해 주는 일
  - 매장 사진을 인스타그램용 정사각형(1080x1080)으로 자르고, 오른쪽 아래에 로고를 넣습니다.
  - 인스타그램 / 네이버 블로그 / 카카오톡 공지 문구를 만들어 줍니다.
  - 결과는 '완성' 폴더 안에 오늘 날짜 폴더로 모아 줍니다.

매주 하는 일은 딱 4단계입니다.


1번. 지난주 사진 치우기
------------------------------------------
  '자료' 폴더 안에 있는 사진은 실행할 때마다 전부 다시 만들어집니다.
  그래서 지난주 사진이 남아 있으면 또 만들어집니다.

  - '자료' 폴더를 엽니다. (홍보자동화 폴더 안에 있습니다)
  - 지난주 사진을 '자료' 폴더 밖으로 옮깁니다. (예: 바탕화면의 새 폴더)
  - 아래 파일은 절대 옮기거나 지우지 마세요.
      로고.png
      가게 정보.txt
      내 말투.txt
  - '완성' 폴더는 건드리지 않아도 됩니다. 지난 결과가 그대로 쌓입니다.


2번. 이번 주 사진 넣기
------------------------------------------
  - 이번 주에 쓸 사진을 '자료' 폴더 안에 넣습니다.
  - 사진 파일은 jpg 또는 png 만 됩니다.
  - 사진 이름은 아무거나 괜찮습니다.
  - 원본 사진은 변하지 않습니다. 복사본이 '완성'에 만들어집니다.


3번. '가게 정보.txt' 에서 이번 주 내용만 바꾸기
------------------------------------------
  '자료' 폴더의 '가게 정보.txt'를 열면 맨 아래에 이런 부분이 있습니다.

      이번 주 홍보할 것:
      - '흑임자 라떼' 5,500원, 국산 흑임자를 직접 갈아서 넣음, 고소하고 달지 않음
      - 오전 11시 이전 방문 시 아메리카노 500원 할인

  이 두 줄만 이번 주 내용으로 바꾸면 됩니다.
  (가게 이름, 위치, 가게 특징은 바뀔 때만 고치세요.)

  지켜야 할 모양
    첫째 줄 (신메뉴)
      - 메뉴 이름은 작은따옴표 ' ' 로 감쌉니다.
      - 바로 뒤에 가격을 씁니다. 숫자 뒤에 '원'을 붙입니다.  예) 6,000원
      - 그 뒤에 설명을 쉼표(,)로 나누어 씁니다.
      - 설명 끝은 '넣음', '않음', '있음', '많음', '없음' 으로 끝내면 알아서 "~합니다"로 바뀝니다.
    둘째 줄 (할인)
      - '할인'이라는 글자가 꼭 들어가야 합니다.
      - '아메리카노 500원 할인' 처럼 '메뉴 이름 + 금액 + 할인' 모양이면 해시태그에도 들어갑니다.
    - 줄 맨 앞의 '-' 와 '이번 주 홍보할 것:' 의 ':' 는 지우지 마세요.
    - 신메뉴 줄과 할인 줄은 각각 1개씩만 인식합니다. 줄이 더 있으면 마지막 줄이 쓰입니다.
    - '말투 느낌' 줄은 프로그램이 읽지 않습니다. 메모용입니다.

  고친 뒤에는 꼭 저장하세요. (Command + S)


4번. 실행하기
------------------------------------------
  방법 A) 가장 쉬운 방법
    바탕화면의 '브릿지 홍보 만들기' 아이콘을 더블클릭합니다.
    작은 창이 열렸다가 끝나면 결과 폴더가 저절로 열립니다.

  방법 B) 아이콘이 안 될 때 (명령어로 실행)
    1) 키보드에서 Command + 스페이스바 를 누르고 '터미널'을 입력해 엔터.
    2) 아래 한 줄을 통째로 복사해서 터미널에 붙여 넣고 엔터.

cd "/Users/leera/Downloads/바이브코딩 실습폴더/홍보자동화" && python3 사진변환.py

  끝나면 이렇게 나옵니다.
      끝! 4장을 저장했어요.
      홍보문구.txt를 저장했어요.
      결과는 '완성/2026-xx-xx' 폴더에 있어요.


결과 보는 곳
------------------------------------------
  홍보자동화 > 완성 > 오늘 날짜 폴더
    - 2026-xx-xx_01.jpg, _02.jpg ...   인스타그램용 사진
    - 홍보문구.txt                      인스타그램 / 블로그 / 카카오톡 문구

  같은 날 또 실행하면 새 폴더를 만들지 않고 같은 날짜 폴더에 이어서 쌓입니다.
  사진 번호는 이어서 늘어나고, 홍보문구.txt 는 아래에 시각과 함께 붙습니다.
  (지워지거나 덮어써지는 것은 없습니다.)


안 될 때 확인할 것 3가지
==========================================

  1) '자료' 폴더를 확인하세요.
     - 사진이 jpg, png 로 들어 있나요?  (다른 형식은 읽지 않습니다)
     - '로고.png' 와 '가게 정보.txt' 가 그대로 있나요?
       * 파일 이름이 바뀌면 안 됩니다. ('가게 정보.txt', '로고.png')
       * 사진이 없으면 "자료 폴더에 jpg, png 사진이 없어요."라고 나옵니다.
       * 로고가 없으면 로고 없이 사진만 만들어집니다.

  2) '가게 정보.txt' 의 모양을 확인하세요.
     - 메뉴 이름을 작은따옴표 ' ' 로 감쌌나요?
     - 가격 뒤에 '원'을 붙였나요?
     - 할인 줄에 '할인'이라는 글자가 있나요?
     - 줄 맨 앞의 '-' 와 ':' 를 지우지 않았나요?
     모양이 틀리면 사진은 만들어지고 문구만 빠지거나 일부 내용이 빠집니다.

  3) 폴더를 옮기거나 이름을 바꾸지 않았나요?
     - '홍보자동화' 폴더를 다른 곳으로 옮기거나 이름을 바꾸면 아이콘이 동작하지 않습니다.
       (방법 B의 명령어도 폴더 위치가 바뀌었으면 안 됩니다.)
     - 아이콘을 처음 열 때 경고가 뜨면, 아이콘을 오른쪽 클릭 > '열기'를 한 번 누르세요.

  그래도 안 되면
     - 터미널에 나온 글(오류 내용)을 복사해서 Claude에게 붙여 넣고 물어보세요.
     - 이 폴더에서 Claude를 열면 오류가 무슨 뜻인지 쉬운 말로 먼저 설명해 줍니다.
